The indefinite integral

A function F is an antiderivative of f if F'=f. If F is one antiderivative, then every other one is F+C for some constant C, because two functions with the same derivative everywhere on an interval differ by a constant. The whole family is written as an indefinite integral:

\int f(x)\,dx=F(x)+C.

Every rule comes from reading a derivative rule backwards. You can always check an answer by differentiating it.

Term by term, and simplify first

Integrals split over sums and constant multiples: \int (af+bg)\,dx=a\int f\,dx+b\int g\,dx. There is no product or quotient rule for integrals, so rewrite products and quotients first. Expand (x+1)^2, divide \frac{x^2+1}{x} into x+\frac1x, and write roots as powers. Then integrate each term.

An extra condition, such as F(0)=2, picks one curve out of the family. That is what dragging the curve through a point does in the graph above.

    Common mistakes

    Forgetting + C

    An indefinite integral is a whole family. Without +C, the answer names only one member.

    Integrating a product factor by factor

    \int x\cdot x\,dx is \frac{x^3}{3}+C, not \frac{x^2}{2}\cdot\frac{x^2}{2}. Multiply out first.

    Using the power rule on 1/x

    With n=-1, the power rule divides by 0. The antiderivative of \frac1x is \ln|x|.
