One-sided limits

The notation \lim_{x\to a^-}f(x) means the limit as x approaches a using only values x. Likewise \lim_{x\to a^+}f(x) uses only x>a. The two-sided limit uses both, so it can exist only when the two sides agree:

\lim_{x\to a}f(x)=L\quad\Longleftrightarrow\quad \lim_{x\to a^-}f(x)=L\ \text{ and }\ \lim_{x\to a^+}f(x)=L

As always, the value f(a) plays no part. Choose the piecewise function with a jump in the graph above. What is f(2), and does it match either side?

Absolute values are two cases

By definition, |u|=u when u\ge 0 and |u|=-u when u<0. So an absolute value hides a piecewise function, and the place where the inside equals 0 is where the two cases meet. If that place is a, each side of a needs its own formula.

Take \lim_{x\to 2}\frac{|x^2-4|}{x-2}. Just to the right of 2, x^2-4>0, so

\lim_{x\to 2^+}\frac{x^2-4}{x-2}=\lim_{x\to 2^+}(x+2)=4.

Just to the left of 2, x^2-4<0, so |x^2-4|=-(x^2-4) and

\lim_{x\to 2^-}\frac{-(x^2-4)}{x-2}=\lim_{x\to 2^-}-(x+2)=-4.

The one-sided limits are 4 and -4. They differ, so the two-sided limit does not exist.

    Common mistakes

    Dropping the bars

    |x-2| is not x-2 and not x+2. It equals x-2 on one side of 2 and -(x-2) on the other.

    Checking one side only

    A table that approaches from the right alone can make a limit look like it exists. Always check both sides.

    Using f(a)

    A piecewise function may define f(a) with one of its pieces. That value says nothing about the limit.

    Treating ∞ as a number

    Writing \lim_{x\to a^+}f(x)=\infty describes how the limit fails to exist. It is not a value the limit equals.
